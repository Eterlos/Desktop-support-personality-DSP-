# Desktop-support-personality-DSP-

---
Проект представляет собой программного агента для рабочего стола,
предназначенного для автоматизации повседневных задач и управления
расписанием. Система будет поддерживать  три независимых канала ввода
данных: через графический интерфейс, посредством контекстного выделения
текста и с помощью голосовых команд. В состав ассистента интегрированы
интеллектуальный чат-бот для интерактивного взаимодействия с
пользователем, а также медиаплеер, обеспечивающий удобное управление
аудиопотоком в едином рабочем пространстве. Взаимодействие с
пользователем и обработка данных реализованы через модули приложения.
