# Scope of work

This is a shared team project. Responsibilities are divided between teammates.

- Current scope: Git, .gitignore and VS Code environment setup.
- Repository file auditing is explicitly assigned: maintain `.repo-audit.json`,
  its script, tests and `Repository audit` workflow. Do not implement app features.
- The user prefers working directly on `main`. Session-start audit reports may
  prompt .gitignore maintenance, but never remove team files or rewrite history.
- Do not create application code, UI, module contracts, databases, test projects,
  solutions or CI workflows unless the user explicitly assigns that work.
- Environment setup does not authorize implementing features or taking work
  assigned to other team members.
- Confirm ownership before starting a new component. The board provides context,
  not authorization to implement everything listed under the user's name.
- Follow .editorconfig; keep secrets and local user data out of Git.
- Do not change global Git identity or global editor settings for this project.
