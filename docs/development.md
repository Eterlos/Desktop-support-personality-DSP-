# Среда разработки

Репозиторий подключён к GitHub через origin. Открывайте корневую папку в VS Code.
Git, .NET SDK и расширения C# / C# Dev Kit уже установлены на этом компьютере.

Настроены .gitignore, .gitattributes, .editorconfig и параметры VS Code.
Исходный README сохранён без изменений. Приложение, решение, тесты,
команды запуска и CI сборки не входят в настройку среды. Структуру приложения
и версию .NET определяет команда.

## Git

Рабочая ветка: `main`, по решению пользователя.
Автор настроен локально: `STopich1`, приватный адрес
`141134649+STopich1@users.noreply.github.com`.
Привязка GitHub к ChatGPT и авторизация локального Git независимы.
Изменить автора для репозитория можно так:

```powershell
git config user.name "Ваше имя"
git config user.email "Ваш email или GitHub noreply"
```

Настройки действуют только для этого репозитория:
`pull.ff=only`, `fetch.prune=true`, `user.useConfigOnly=true`.
Последняя требует явно указать автора перед коммитом.

## Проверка файлов

По отдельному поручению добавлена [автопроверка содержимого репозитория](repository-audit.md):
модели, сборочные файлы, бинарные библиотеки, архивы и файлы больше 10 МиБ.
Она не собирает приложение и не реализует функциональность команды.
